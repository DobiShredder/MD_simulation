# OPES Expanded multithermal / OPES Expanded 다중온도

References: Amber 2026 and PLUMED 2.10
([OPES_EXPANDED](https://www.plumed.org/doc-v2.10/user-doc/html/_o_p_e_s__e_x_p_a_n_d_e_d.html)).

## 한국어

`ECV_MULTITHERMAL`과 `OPES_EXPANDED`로 단일 replica에서 300–500 K를
sampling합니다. Input과 실행 방법은 [multithermal/](multithermal/README.md)에
있습니다.

## English

The input defines a 300–500 K expanded ensemble with ECV_MULTITHERMAL and
samples it in one replica using OPES_EXPANDED. See
[multithermal/](multithermal/README.md) for inputs and run instructions.
