# Visual assets / 시각화 자료

## 한국어

README에서 사용하는 개념도를 한곳에 모았습니다.

- `simulation/`: force field, enhanced sampling과 free-energy method 개념도
- `analysis/`: dimension reduction과 clustering 개념도

그림은 실제 simulation 결과가 아닌 schematic입니다. `Illustrative data`로
표시한 point도 method 차이를 설명하기 위해 만든 값이며 population이나 free
energy를 나타내지 않습니다.

## English

This directory contains the conceptual figures used by the tutorial READMEs.
`simulation/` covers force fields, enhanced sampling, and free-energy methods;
`analysis/` covers dimensionality reduction and clustering.

The figures are schematics rather than simulation results. Points marked as
`Illustrative data` explain method differences and do not represent populations
or free energies.
