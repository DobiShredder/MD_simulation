# Basic analysis / 기본 구조 분석

## 한국어

cpptraj로 가장 자주 계산하는 구조 지표와 기하학적 collective variable을
Chignolin trajectory에서 계산합니다. RMSD처럼 fitting에 의존하는 값과
distance처럼 원자 selection에 의존하는 값을 구분해 다룹니다.

- [RMSD, RMSF, and Rg](2.1_RMSD_RMSF_Rg/)
- [Geometry](2.2_Geometry/)

## English

Core cpptraj structural observables and geometric collective variables using
the Chignolin trajectory. The examples distinguish fitting-dependent metrics
from quantities defined by explicit atom selections.
