# t-SNE

## 한국어

구현 예정: 표준화한 feature 또는 PCA projection의 Python t-SNE 시각화.
Random seed, perplexity와 scaling을 output에 기록합니다. t-SNE 거리와 밀도는
thermodynamic quantity로 사용하지 않습니다.

## English

Python examples visualize standardized features or PCA projections. Random
seed, perplexity, and scaling are recorded; distances and densities are not
interpreted as thermodynamic quantities.
