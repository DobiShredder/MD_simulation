고차원 trajectory feature를 저차원으로 투영합니다. PCA 계산은 cpptraj를

- [t-SNE](4.2_tSNE/)

## English

Low-dimensional projections of trajectory features. PCA uses cpptraj plus
Python visualization; t-SNE is presented as a Python visualization method.
