# Clustering / 군집화

## 한국어

Python으로 trajectory feature 또는 PCA projection을 clustering하고 원본 frame
번호를 유지합니다. t-SNE embedding은 clustering 입력으로 사용하지 않습니다.

- [K-means](5.1_KMeans/)
- [DBSCAN](5.2_DBSCAN/)

## English

Python clustering of trajectory features or PCA projections with retained
source-frame indices. t-SNE embeddings are not used as clustering input.
